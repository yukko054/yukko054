### 👋 About

I build whole products end to end — from the Telegram mini app a guest opens,
to the CRM and analytics the team works in, to the server it all runs on.

- 🏗️ **Now:** a monorepo platform for a hospitality business — guest mini app, task tracker (CRM), audit office, knowledge hub and analytics, all on one API
- 🤖 **Also:** Telegram & Discord bots, parsers, monitoring tools
- 🧠 **Into:** AI coding agents — skills, harness configs, agent workflows
- 🔐 **Care about:** security audits, backups that actually restore, fast pages
